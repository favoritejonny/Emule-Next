Subject: Permission request for the name eMule Next and mule artwork

Dear eMule Project team,

I maintain an independent, non-commercial Windows fork of the GPL-licensed
eMule client, based on the eMule Community source. The project is currently
named eMule Next and is intended to remain compatible with the eD2K and Kad
networks. Its public repository is:

https://github.com/favoritejonny/Emule-Next

Before publishing source or binaries, I would like to clarify the permitted
use of the eMule name and artwork. The project would be clearly described as
an independent community fork that is not affiliated with, endorsed by or
sponsored by the official eMule Project.

Would you be willing to grant written permission for this fork to:

- use the name "eMule Next" for the project and Windows client;
- retain and redistribute inherited eMule name and mule artwork contained in
  the GPL-derived source and binaries;
- use newly drawn, clearly derivative mule-head icons for the fork;
- distribute modified source and Win32/x64 binaries under
  GPL-2.0-or-later, while retaining upstream copyright notices and clear
  attribution?

Please let me know whether permission can be granted and whether you require
specific wording, visual separation, attribution or other conditions. If this
use is not permitted, I will rename the project and replace the affected
branding before publication.

Thank you for your time and for the eMule Project's work.

Kind regards,

Jonny Favorite
