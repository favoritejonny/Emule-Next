# Name and artwork permission request for the eMule Project

Official administrative/legal contact checked on 2026-08-29:
`info@emule-project.net`

Source:
<https://www.emule-project.com/home/perl/general.cgi?l=1&rm=contact>
(select **Administrative issue**; the site requests English or German).

Status: **written clarification received from the official eMule Project
administrative/legal contact on 2026-08-29.** The original email, sender and
headers are retained privately by the project maintainer and must not be added
to the public repository.

The DevTeam explained that it does not give special written permission because
most of the requested use is already covered by the GPL 2.0 terms under which
eMule is published. It stated:

> We consider artwork included in the source files as licensed under the GPL
> 2.0 too.

For the name, the DevTeam did not claim certainty about any current registered
trademark and noted that implicit rights might exist. It nevertheless stated
that it does not intend to enforce trademark rights against forks that do not
pretend to be the official or original eMule, and confirmed that the customary
`eMule [own name]` naming pattern is fine. `eMule Next` follows that pattern.

The project therefore records the name and source-artwork issue as resolved
for this independent, non-commercial GPL fork, subject to these continuing
conditions:

- comply fully with GPL-2.0-or-later and all retained notices;
- present eMule Next clearly as an independent community fork;
- never imply that it is the official/original eMule or is endorsed by the
  eMule Project;
- obtain fresh specialist review before materially different commercial,
  merchandising or branding use.

Subject: Permission request for the name eMule Next and mule artwork

Dear eMule Project team,

I maintain an independent, non-commercial Windows fork of the GPL-licensed
eMule client, based on the eMule Community source. The project is currently
named eMule Next and is intended to remain compatible with the eD2K and Kad
networks. Its public repository is:

https://github.com/favoritejonny/Emule-Next

Before publishing source or binaries, I would like to clarify the permitted
use of the eMule name and artwork. The project would be clearly described as
an independent community fork that is not affiliated with, endorsed by or
sponsored by the official eMule Project.

Would you be willing to grant written permission for this fork to:

- use the name "eMule Next" for the project and Windows client;
- retain and redistribute inherited eMule name and mule artwork contained in
  the GPL-derived source and binaries;
- use newly drawn, clearly derivative mule-head icons for the fork;
- distribute modified source and Win32/x64 binaries under
  GPL-2.0-or-later, while retaining upstream copyright notices and clear
  attribution?

Please let me know whether permission can be granted and whether you require
specific wording, visual separation, attribution or other conditions. If this
use is not permitted, I will rename the project and replace the affected
branding before publication.

Thank you for your time and for the eMule Project's work.

Kind regards,

Jonny Favorite
