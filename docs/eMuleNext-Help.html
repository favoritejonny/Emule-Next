eMule Next - Quick guide

Version 1.0.0 alpha. This guide is included with the program and works offline.

Getting started

In Preferences, choose the completed and temporary folders. Connect, search, add a result and monitor it in Transfers.

Security and privacy

Download only material you are entitled to receive, scan unknown files and never share personal folders.

Troubleshooting

If it does not connect, check the Internet connection, firewall and ports. Slow downloads need available sources and time.

Information

This local guide works without Internet access. Use the official project channels for releases and support.
