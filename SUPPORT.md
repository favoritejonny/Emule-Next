# Support

eMule Next is an independent community project maintained by volunteers. It
is not an official eMule Project release.

## Before opening an issue

1. Confirm that you are testing an eMule Next package obtained from this
   repository's Releases page.
2. Record the version, Win32 or x64 architecture, normal or portable package,
   and Windows version.
3. Restart the client once and check whether the problem is reproducible.
4. Remove personal data from screenshots and logs, including usernames, IP
   addresses, paths, shared-file names and search terms.
5. Search existing issues for the same behavior.

Use the **Bug report** form for a reproducible malfunction and the **Feature
request** form for an improvement. GitHub Issues are not a general download,
server-list or copyrighted-content support channel.

## Safety and privacy

Never post passwords, tokens, private keys, `preferences.dat`, `cryptkey.dat`,
credit files, complete configuration folders or unreviewed crash dumps. A
crash dump can contain private data from memory; provide it only through a
private channel explicitly arranged by a maintainer.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not
be disclosed in a public issue.
